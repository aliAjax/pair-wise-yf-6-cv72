# 上门施工放行台

由「家庭维修事项」扩展而来，端口规划：`5114`

```bash
npm install
npm run dev
```

单页应用，无新增页面、运行时依赖或后端服务；原生 ES Module 按三层拆分：

- `src/model.js` 数据模型：维修事项、三道前置、技师、约次、整改项、完工登记、只追加事件流，以及 localStorage 读写。
- `src/rules.js` 规则流转：
  - 每项维修须依次完成 **现场测量 → 备料 → 业主确认** 三道前置；任一未完成不得预约上门，原排期不变，卡片旁标明卡点。
  - 备料齐备后按 **技师技能覆盖 → 当日两小时时段占用 → 同址事项合并** 排期；候选技师全冲突时同址整组整次拒绝，不拆分，保留候选顺序。
  - 开工前检查命中 **断电 / 擅自扩项 / 安全条件不符** 立即停止并生成整改项，原约冻结；同约整改全部复检通过才释放原约。
  - 完工登记实际费用与业主验收：验收退回或实际费用超承诺两成，一律退回处理中；登记与流转历史只追加。
  - 四项统计：待放行、已排期待开工、停工整改、已验收。
- `src/components.js` 页面组件：统计、筛选、新增表单、事项卡片（前置进度、预约与拒绝、约次与检查、整改、完工、历史）。
- `src/main.js` 事件接线与本地数据同步：localStorage 刷新保留，并通过 `storage` 事件做多标签页同步。
